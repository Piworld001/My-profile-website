# Personal Portfolio Website

## About the Project

This project is a personal portfolio website created using HTML. It was developed to showcase my background, skills, projects, and professional interests as a Computer Science student and aspiring technology professional.

## Pages

The website contains the following pages:

- Home
- About
- Skills
- Projects
- Contact

## Technologies Used

- HTML5
- Semantic HTML
- Basic web accessibility
- Multimedia elements
- Images and links

## Features

- Responsive viewport setup
- Semantic HTML structure
- Navigation between pages
- Personal profile information
- Skills and projects sections
- Contact page
- Image integration
- Accessible image descriptions using alt text
